## 🚀 快速开始

### 安装依赖

```bash
cd stock_analysis
pip install -r requirements.txt
```

### 运行完整分析

```bash
# 分析默认自选股
py scripts/main.py

# 分析指定股票
py scripts/main.py --watchlist 000001,600000,000002,600519

# 只采集数据
py scripts/stock_collector.py

# 只技术分析
py scripts/technical_analysis.py

# 只生成报告
py scripts/report_generator.py
```

### 查看结果

```bash
# 查看报告
ls reports/

# 查看数据
ls data/
```
